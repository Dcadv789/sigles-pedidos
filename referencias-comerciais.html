Solicitações de Aproveitamento de Estudos

Arquivo: Adiçoes do SIGLES.docx
Nova aba — Aproveitamento de Estudos — Alunos não usuários do Sistema · parágrafos 23–50

Parágrafo 23

NOVA ABA – APROVEITAMENTO DE ESTUDOS – Alunos não usuários do Sistema:

Parágrafo 24

- O aluno deverá acessar o sistema para cadastrar (já temos um link de acesso para externos, para solicitar publicações, verificar se pode ser este mesmo acesso para as solicitações de aproveitamento de estudos;

Parágrafo 25

- Deve haver campos para indicar a disciplina para à qual o aluno solicita o aproveitamento de estudos, como o código e nome da disciplina, que poderá ser puxado da aba Disciplinas, para facilitar e agilizar, não precisa citar o semestre;

Parágrafo 26

- O sistema deverá puxar do cronograma atual, o nome do docente responsável pela disciplina, por meio do código dela, independentemente do semestre, porém, do ano corrente. (Muitas vezes ocorre divisão das turmas onde 2 ou mais docentes ministram aula, ou também pode acontecer de outro docente, diferente daquele citado na ementa, esteja ministrando a disciplina.

Parágrafo 27

- O aluno deve inserir os documentos solicitados em PDF, clicando nos ícones, formulário de requerimento, histórico da(s) disciplina(s) cursada(s), ementa(s) da(s) disciplina(s) cursada(s), pois pode ser mais que uma, ou inserir todos os documentos em um único arquivo, clicando no ícone com o mesmo nome.

Parágrafo 28

- O sistema somente deixará salvar a solicitação, após o aluno inserir todos os documentos individualizados ou em um arquivo único.

Parágrafo 29

- O aluno pode inserir quantas solicitações quiser, clicando no botão “+”

Parágrafo 30

Um mesmo aluno pode inserir várias solicitações de aproveitamento, para um ou para vários docentes diferentes, espera-se que o sistema envie os pedidos em separados, da forma que foi cadastrado.

Parágrafo 31

- Após envio pelo aluno, o sistema me notifica de que existe solicitação de aproveitamento aguardando análise. Pode-se apenas visualizar os documentos dentro do sistema ou em uma aba separada, do mesmo modo que o plano de ensino.

Parágrafo 32

- Após constatar se os arquivos estão ou não estão completos, deve haver duas possibilidades para meu encaminhamento: Devolver ao aluno para ajustes ou enviar para a análise do docente.

Parágrafo 33

- Deve haver um campo para eu explicar ao aluno o motivo da devolução.

Parágrafo 34

- O sistema envia notificação ao solicitante de que há uma solicitação de aproveitamento de estudos devolvida para ajustes. Essa notificação deverá ocorrer no mesmo e-mail registrado pelo solicitante, no momento que acessou o sistema.

Parágrafo 35

- Feitos os ajustes, o aluno reenvia a solicitação.

Parágrafo 36

- O sistema me notifica que a solicitação retornou para minha análise.

Parágrafo 37

- Estando tudo certinho, eu clico no botão “enviar p/ análise”.

Parágrafo 38

- O docente recebe a notificação de que há solicitação de aproveitamento de estudos aguardando a análise e manifestação dele.

Parágrafo 39

- O docente pode visualizar os arquivos, em aba separada e também imprimir, caso prefira.

Parágrafo 40

Deve haver 5 opções para que o docente emita seu parecer:

Parágrafo 41

- Deve haver um botão para que o docente possa apenas clicar deferir ou não deferir a solicitação, após isso, “salvar e enviar”, para que o sistema possa encaminhar ao Serviço de Graduação. O sistema de me informar desse encaminhamento.

Parágrafo 42

- O docente visualiza e/ou baixa os documentos, podendo escrever o parecer no próprio formulário impresso, inserindo-o novamente no sistema (deve haver um botão para a inserção) e clicando no botão “salvar e enviar”.

Parágrafo 43

- Caso o docente visualize os arquivos e queira somente inserir o arquivo com o parecer, deve haver o botão de inserção, e após, “salvar e enviar”

Parágrafo 44

- Deve haver espaço para que o docente escreva sua decisão – com pelo menos 250 letras, na própria tela inicial (após visualizar os arquivos), depois, “salvar e enviar”

Parágrafo 45

- Deve ser possível ao docente devolver a solicitação para ajustes, inserção de documentos, ou para que o aluno possa realizar uma prova para comprovação dos estudos. Nesse caso, o sistema envia a notificação com o despacho do docente para o solicitante, com cópia para mim.

Parágrafo 46

- Se possível, o Serviço de Graduação não precisar se cadastrar no sistema para acessar esses documentos, apenas abrindo o link do informe enviado pelo sistema, o Serviço vai diretamente na solicitação finalizada pelo docente, onde poderá baixar os arquivos, ou apenas visualizar.

Parágrafo 47

- O processo será considerado concluído quando o SVG clicar no link para acessar os documentos da solicitação, que deve aparecer como deferida ou não deferida (tudo deve ser o mais prático possível para o SVG e para o Departamento).

Parágrafo 48

Todos os documentos devem ficar guardados, por pelo menos 2 anos.

Parágrafo 49

Na conclusão do processo, o sistema deve enviar notificação de conclusão da solicitação para o mim, com cópia para o solicitante.

Parágrafo 50

- Poder filtrar e emitir relatórios com as informações que desejar: nome do aluno, nome do docente responsável, código da disciplina para à qual foi solicitado o aproveitamento, datas, deferidos e não deferidos; Baixar em excel.
